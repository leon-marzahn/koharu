# 05: Character sheet (manual)

**What to build:** A per-project Character sheet with a Project panel tab. Each character has source name, target name, speech style, appearance and notes. You add, edit and delete entries by hand; all entries go into every translation prompt. Saved inside the project and undoable.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Project panel opens with a Characters tab
- [x] Entries persist across restarts and are undoable
- [x] Every entry appears in every translation request
- [x] Controls are labelled and keyboard-operable
- [x] Prompt-payload, stage and component tests cover the above

# 05: Character sheet (manual)

**What to build:** A per-project Character sheet with a Project panel tab. Each character has source name, target name, speech style, appearance and notes. You add, edit and delete entries by hand; all entries go into every translation prompt. Saved inside the project and undoable.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Project panel opens with a Characters tab
- [ ] Entries persist across restarts and are undoable
- [ ] Every entry appears in every translation request
- [ ] Controls are labelled and keyboard-operable
- [ ] Prompt-payload, stage and component tests cover the above
